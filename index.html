The Viridien Story: Security & AI Modernization

A chronological look at how I architected Viridien's DevSecOps transformation—from introducing the first code scanner to deploying AI agents for infrastructure ops.

2023

SonarQube Implementation & Code Scanning Inception

When I joined Viridien, there was a pressing need to introduce code scanning into the CI/CD workflow to identify bugs and vulnerabilities where none existed previously. I spearheaded the entire lifecycle—from PoC and presenting to VPs, to deployment, configuration, and authoring the GitLab CI/CD templates.

Massive Scale
Scanned ~250+ projects covering ~800K lines of code, identifying over 2000+ issues across the organization.
Cost-Saving Innovation
Integrated community plugins to enable multi-branch scanning and Merge Request decoration on the Community Edition, delivering 'Developer Tier' features while saving significant licensing costs.
Late 2024

Secure Software Development Lifecycle (SSDLC) Internal PaaS

Following the release of Secure Coding Policy V1, I identified critical gaps: lack of controls, lack of GitLab DR strategies, and fractured toolchains. I conceptualized and spearheaded an internal Platform-as-a-Service to centralize governance, secure 3rd-party ingress, ensure license compliance, and implement Resilient SCM via GitLab Geo.

Cross-Functional Execution
Led requirement gathering, vendor negotiations (GitLab Enterprise), hardware procurement, and defined toolchain ownership (IT manages deployment, DevOps manages migrations/policies).
Enterprise Buy-in
Produced open-source vs enterprise comparisons and secured budget allocation for a 3-year Enterprise Edition contract. An actively thriving project today.
2024-2025

Secure Policy Refinement & ScanOSS Integration

Collaborated directly with the Enterprise Cybersecurity team to refine the overarching Secure Coding Policy, strengthening the organization's security posture. Concurrently, led the implementation of ScanOSS—a powerful code snippet scanner designed to protect the company from IT infringement claims.

Snippet Analysis
Integrated open-source code snippet analysis directly into the GitLab-EE workflow using the robust SSDLC processes previously established.
Compliance Posture
Provided total visibility into third-party code ingestion and legal/license compliance boundaries.
2025

AI-Assisted Vulnerability Triage & MR Generation

With total visibility over our codebase established through SSDLC and ScanOSS, the next frontier was developer fatigue. I integrated internal AI models to digest our security findings, automatically triage vulnerabilities, and proactively generate Merge Requests (MRs) with suggested fixes directly in GitLab-EE.

Developer Experience
Transformed the developer pain-point of manual vulnerability remediation into an AI-augmented review-and-merge workflow.
Agentic Ecosystem
Gained deep exposure to writing AI Skills, utilizing hybrid model assignments to balance cost vs token optimization for various background agent tasks.
Present

Modernizing IT Ops with MCP, HolmesGPT & k8sgpt

Currently revolutionizing Kubernetes and overall IT operations by implementing HolmesGPT and k8sgpt. By integrating and writing custom Model Context Protocol (MCP) servers (Zabbix MCP, Atlassian MCP, GitLab MCP, k8s MCP), we enable AI agents to "talk" to our infrastructure—diagnosing issues, remediating incidents, and monitoring environments efficiently.

API to MCP Conversion
Modernizing existing internal services by exposing their APIs as MCP tools, making them easily consumable by autonomous agents across the organization.
The Future of Ops
Creating an ecosystem where natural language queries can safely interrogate, diagnose, and resolve production infrastructure issues.
